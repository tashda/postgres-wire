# ``PostgresKit``

PostgresKit is a high-level library for interacting with PostgreSQL databases in Swift.

## Overview

This library provides a user-friendly API for executing queries, managing transactions, and interacting with PostgreSQL. It is built on top of `PostgresWire`.

## Features

- High-level API for PostgreSQL operations.
- Built-in connection pooling and transaction management.
- Seamless integration with standard Swift types.
