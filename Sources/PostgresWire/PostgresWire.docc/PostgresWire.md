# ``PostgresWire``

PostgresWire is a Swift-native implementation of the PostgreSQL wire protocol.

## Overview

This library provides the core protocol implementation for interacting with PostgreSQL databases. It is used as the foundation for higher-level libraries like `PostgresKit`.

## Features

- Fully asynchronous using Swift Concurrency.
- High-performance serialization and deserialization.
- Support for standard PostgreSQL features.
